## Общее описание

Cerebra AI - это современная система искусственного интеллекта на основе трансформерной архитектуры, аналогичной GPT. Проект реализует:
- 🚀 GPT-подобную трансформерную архитектуру для генерации текста
- 🌐 Интеграцию с веб-поиском для получения актуальной информации
- 📚 Автоматическое обучение на реальных диалогах из чата
- 💾 Сохранение и загрузка прогресса обучения
- 🎯 Генеративное обучение по принципу next token prediction

**Название модели:** Synthesis-L1  
**Архитектура:** GPT Transformer (авторегрессивная генерация текста)  
**Язык:** Русский (с поддержкой русскоязычных диалогов)  
**Параметров:** ~29 миллионов  
**Размерность:** 512 dim  
**Attention Heads:** 8  
**Слои:** 6 трансформерных блоков

## Основные компоненты

### 1. `main.py` - Главный интерфейс
- **Отвечает за:** Меню, управление режимами работы, взаимодействие с пользователем
- **Реализует:**
  - 💬 Режим чата с ИИ

  - 🌐 Режим веб-поиска
  - ℹ️ Отображение информации о системе
  - 💾 Сохранение модели
  - 🗑️ Очистка истории диалогов

### 2. `cerebra/core.py` - Ядро системы
- **Класс `Cerebra`:** Главный контроллер всей AI системы
- **Функциональность:**
  - Загрузка/сохранение моделей
  - Обработка чата с ИИ
  - Управление обучением
  - Веб-поиск (при необходимости)
  - Сбор статистики

### 3. `cerebra/models/gpt_model.py` - GPT трансформер
- **Класс `GPTTransformer`:** Основная нейросеть
- **Компоненты:**
  - `PositionalEncoding` - Позиционное кодирование
  - `MultiHeadAttention` - Механизм внимания
  - `TransformerBlock` - Блок трансформера
  - Метод `generate()` - Генерация текста с top-k и top-p sampling

### 4. `cerebra/models/tokenizer.py` - Токенизатор
- **Класс `SimpleTokenizer`:** Токенизатор для русского языка
- **Функции:**
  - Построение словаря из обучающих данных
  - Кодирование/декодирование текста
  - Обработка специальных токенов

### 5. `cerebra/models/training.py` - Обучение
- **Класс `TextDataset`:** Датасет для обучения
- **Функции:**
  - `prepare_training_data()` - Подготовка данных из диалогов
  - `train_gpt_model()` - Обучение модели на next token prediction

### 6. `cerebra/dialogue_training.py` - Автоматическое обучение
- **Класс `DialogueCollector`:** Сборщик диалогов
- **Функции:**
  - Сохранение всех диалогов из чата
  - Автоматическое обучение на реальных разговорах
  - Подготовка данных для обучения

### 7. `cerebra/web_search.py` - Веб-поиск
- **Класс `WebSearcher`:** Поиск информации в интернете
- **Функции:**
  - Поиск через DuckDuckGo
  - Извлечение и обработка результатов
  - Интеграция с чатом

## Как работает ИИ

### 1. Архитектура трансформера

**GPTTransformer** использует:
- 6 трансформерных блоков
- 8 attention heads
- 512 размерность модели
- Позиционное кодирование для понимания порядка слов
- Masked self-attention для каузальной генерации

### 2. Процесс генерации

1. **Вход:** Текст пользователя токенизируется
2. **Embedding:** Токены преобразуются в векторы
3. **Трансформер:** Проход через 6 слоев с вниманием
4. **Генерация:** Используется top-k + top-p sampling
5. **Выход:** Декодирование в текст

### 3. Обработка запроса

```python
def chat(self, message, use_web_search=False):
    if use_web_search:
        # Сначала ищем в интернете
        response = web_searcher.get_answer_from_web(message)
    else:
        # Генерируем моделью
        response = self.active_model.process(message)
    
    # Сохраняем для обучения
    self.active_model.dialogue_collector.add_exchange(message, response)
    return response
```

### 4. Автоматическое обучение

1. **Сбор данных:** Все диалоги сохраняются в `training_data/dialogues.json`
2. **Подготовка:** Тексты формируются для next token prediction
3. **Обучение:** Модель обучается на реальных диалогах
4. **Улучшение:** После обучения модель генерирует лучшие ответы

## Недоработки и ограничения

### 1. Технические ограничения
- **Ограниченный словарь:** 10,000 токенов может быть недостаточно для сложного русского языка
- **Маленькая модель:** 29M параметров - относительно мало для современных стандартов
- **Ограниченная длина последовательности:** 512 токенов для контекста
- **Отсутствие продвинутой обработки ошибок:** Некоторые исключения могут прервать выполнение

### 2. Функциональные ограничения
- **Нет долгосрочной памяти:** Модель не сохраняет контекст между сессиями (только в текущем диалоге)
- **Ограниченное понимание контекста:** Модель может "забывать" начало длинного диалога
- **Нет модерации:** Модель может генерировать неподобающий контент
- **Зависимость от качества данных:** Качество ответов напрямую зависит от качества обучающих диалогов

### 3. Потенциальные улучшения
- **Улучшение токенизатора:** Использование BPE или SentencePiece для лучшей обработки русского языка
- **Увеличение размера модели:** Более глубокая архитектура для лучшего понимания
- **Добавление памяти:** Реализация механизмов долгосрочной памяти
- **Модерация контента:** Фильтрация нежелательного контента
- **Улучшение генерации:** Лучшие методы декодирования и перплексии
- **Расширение функционала:** Поддержка изображений, аудио и других модальностей
- **Интерфейс администратора:** Управление моделью через веб-интерфейс
- **API:** REST API для интеграции с другими системами

### 4. Известные баги
- **Проблемы с размерностями:** В некоторых случаях могут возникать ошибки при генерации
- **Ошибки в токенизации:** Некоторые русские слова могут неправильно токенизироваться
- **Проблемы с CUDA:** Иногда возникают ошибки при использовании GPU
- **Утечки памяти:** При длительной работе возможны утечки памяти
