# Cerebra AI - Веб-версия

## Запуск веб-версии

Для запуска веб-интерфейса Cerebra AI выполните:

```bash
python web_version.py
```

По умолчанию веб-интерфейс будет доступен по адресу: http://0.0.0.0:8000

## Настройка параметров

Вы можете настроить хост и порт с помощью переменных окружения:

```bash
export CEREBRA_HOST=127.0.0.1
export CEREBRA_PORT=8080
python web_version.py
```

Или в одной команде:

```bash
CEREBRA_HOST=127.0.0.1 CEREBRA_PORT=8080 python web_version.py
```

## Особенности веб-версии

- Веб-интерфейс с чатом в реальном времени
- Поддержка выбора модели (L1, L2, L3)
- Возможность включения веб-поиска
- Поддержка плагинов (калькулятор, время, дата и др.)

## Зависимости

Для работы веб-версии требуются дополнительные зависимости, указанные в requirements.txt:

- fastapi
- uvicorn
- websockets
- nest-asyncio
- pydantic

Установить зависимости можно командой:

```bash
pip install -r requirements.txt
```
