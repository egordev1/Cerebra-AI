# Совместимость с AMD GPU для Cerebra AI

## Внесенные изменения

### 1. Модуль `/workspace/cerebra/gpu_acceleration.py`

- **Удалены импорты CUDA-специфичных функций**: `from torch.cuda.amp import autocast, GradScaler`
- **Изменена логика определения устройства**: 
  - Теперь система проверяет наличие AMD GPU и автоматически переключается на CPU
  - Добавлена поддержка MPS (Apple Silicon) для полноты
- **Обновлены все методы класса**:
  - `move_to_device()`: теперь всегда перемещает на выбранное устройство без проверки CUDA
  - `move_tensor_to_device()`: аналогично без проверки CUDA
  - `autocast_context()`: заменен на пустой контекстный менеджер, так как `autocast` специфичен для CUDA
  - `scale_loss()`: убрана логика масштабирования, так как `GradScaler` специфичен для CUDA
  - `update_scaler()`: убрана логика scaler'а, используется только `optimizer.step()`
  - `is_gpu_available()`: теперь возвращает True для CUDA и MPS, но не для CPU
  - `get_memory_info()`: добавлена поддержка MPS и корректная обработка для CPU

### 2. Модуль `/workspace/cerebra/core.py`

- **Обновлена обработка ошибок**: теперь `except` блок ловит `(torch.cuda.OutOfMemoryError, RuntimeError)` и включает очистку памяти для всех типов устройств
- **Добавлена очистка памяти**: для CPU и MPS систем добавлена очистка памяти через `gc.collect()`

### 3. Модуль `/workspace/cerebra/utils.py`

- **Обновлена функция `print_system_info()`**: теперь она проверяет тип GPU и выводит предупреждение для AMD GPU, информируя пользователя о переключении на CPU

## Особенности работы с AMD GPU

1. **Автоматическое определение**: система автоматически определяет AMD GPU и переключается на CPU для обеспечения совместимости
2. **Безопасная работа**: все CUDA-специфичные функции заменены на безопасные альтернативы
3. **Сохранение производительности**: при работе на CPU система использует все доступные оптимизации

## Рекомендации по установке

Для полной совместимости с AMD GPU рекомендуется установить CPU-версию PyTorch:

```bash
pip install torch>=2.0.0+cpu -f https://download.pytorch.org/whl/torch_stable.html
```

Или использовать файл `cpu_requirements.txt`:

```bash
pip install -r cpu_requirements.txt
```
