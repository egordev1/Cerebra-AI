# 🧠 Cerebra AI

Интеллектуальная текстовая AI система с моделью **Synthesis-L1**.

## Установка

```bash
pip install -r requirements.txt
python setup.py develop
```

## Запуск

Проект поддерживает несколько режимов работы:

1. **Консольный интерфейс** - простой текстовый интерфейс
2. **Графический интерфейс (GUI)** - визуальный интерфейс с историей чата
3. **Расширенный консольный интерфейс** - режим с меню и возможностью обучения

Для запуска используйте команду:
```bash
python run_cerebra.py
```

Затем выберите нужный режим работы.

## Особенности GUI

- Визуальный интерфейс с историей чата
- Возможность сохранения истории
- Отдельное окно для обучения модели
- Информация о системе
- Поддержка многопоточности для плавного интерфейса
